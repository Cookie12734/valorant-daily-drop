# DAILY DROP

VALORANTの本日の個人ショップを表示する、日本語のWebサイトです。Riotのログイン画面でログインすると、スキン画像・VP価格・更新までの残り時間を取得します。

## 起動する

Node.js 22.12以降とデスクトップ環境が必要です。Windowsを主な動作確認対象にしています。

```powershell
git clone https://github.com/Cookie12734/valorant-daily-drop.git
cd valorant-daily-drop
npm ci
npm start
```

ブラウザーで `http://127.0.0.1:4173` が開きます。**Riotでログイン**を押し、別ウィンドウに表示されるRiotのページでユーザー名・パスワードを入力してください。二段階認証やCAPTCHAが表示された場合も、そのRiot画面上で完了します。認証後はショップを自動取得します。ゲームの起動、Developer PortalのAPIキー、JSONファイルの受け渡しは必要ありません。

- 初回起動時にElectronの実行ファイルをダウンロードします。
- ログイン中のキャンセル、ログアウト、取得の再試行に対応します。
- Riotユーザー名・パスワードによるログインが対象です。Google・Appleなどの外部サービス経由のログインには対応していません。
- 終了するには、起動したターミナルで `Ctrl+C` を押します。再起動後や認証期限切れには再ログインしてください。
- ポートが使用中の場合は、起動前に `$env:PORT = '4174'` を設定します。

**通常のWebサイトだけで認証が完結する方式ではありません。** ブラウザーの同一オリジン制限があるため、認証用のElectron補助アプリをPC上で起動します。ショップ画面は通常のブラウザーで動きます。静的ホスティング版はプレビューと起動案内・ファイル表示を提供し、補助アプリをクラウド上で動かすことはできません。

## 認証とデータ

1. 補助アプリが、分離されたRiotの実ログインページを表示します。独自のパスワード入力フォームはありません。
2. 非公式クライアント認証のリダイレクトを検査し、メモリー内でアクセストークンを受け取ります。リダイレクト先とランダムなstateを照合します。
3. Riotのuserinfo・Entitlements・Geoエンドポイントから、アカウント識別子・ショップ用トークン・リージョンを取得します。
4. Riotの内部Storefront APIから商品と価格を取得し、[Valorant-API](https://valorant-api.com/)の公開メタデータで名前と画像を補います。

パスワードはRiotのページへ直接入力し、アプリ側で読み取りません。認証トークンはPCのメモリー内に保持し、ログ・ファイル・ブラウザーのストレージへ保存しません。認証画面のCookieは非永続セッションを使用し、画面を閉じた際に削除します。Web画面に返すのはスキンID・価格・取得／更新時刻・リージョンだけです。外部のメタデータAPIにはRiotトークンを送りません。

ローカルサーバーは `127.0.0.1` にのみ待ち受け、認証・ログアウト・ショップ取得は同一オリジンのJSON POSTに限定します。ネットワークへの公開やリバースプロキシによる多人数共有は想定していません。

## 非公式方式の制約

Riotの[公式VALORANT API](https://developer.riotgames.com/docs/valorant)には個人ショップ取得用の公開エンドポイントがありません。この実装は[非公式認証の調査資料](https://valapidocs.techchrism.me/endpoint/auth-request)と[Storefront仕様](https://valapidocs.techchrism.me/endpoint/storefront)に基づくもので、承認済みRSO連携ではありません。Riotのポリシーではオンラインショップ追跡が承認対象外に挙げられています。

Riot側の仕様変更、埋め込みブラウザー制限、CAPTCHA、アクセス制限によって利用できなくなる可能性があります。認証制限の回避処理はありません。認証のコールバック形式が変わった場合は失敗として表示します。

**2026年10月4日、実アカウントでのRiotログインからv3 API経由の個人ショップ表示まで、利用者による動作確認が完了しました。** 自動テストも通過しています。非公式APIのため、今後のRiot側の変更に対する動作保証はありません。

## 補助機能

従来の起動中Riot Clientからの取得を使う場合は `npm run start:client`、ショップJSONを書き出す場合は `npm run shop` を実行します。この方式には起動中のVALORANTの有効なセッションが必要です。`exports/shop.json` はGit追跡対象外で、サイトの使い方画面から読み込めます。ファイルはブラウザー内で処理します。

## 開発・検証

```powershell
npm test
```

`dist/` はビルド不要の静的Web画面、`scripts/desktop.mjs` は認証ウィンドウ、`scripts/riot-login.mjs` は認証・ショップ取得処理、`scripts/local-server.mjs` はローカル配信です。認証画面に必要なElectron以外はNode.js標準機能を使用します。

テストでは、リダイレクト先・state・有効期限・重複パラメーターの検証、認証からショップ取得までのリクエスト、認証情報の除外、ログアウト時の競合、HTTPオリジン制限、パストラバーサル、商品・価格・時刻の検証を確認します。

VALORANTおよびスキン画像の権利はRiot Gamesに帰属します。本プロジェクトはRiot Gamesと提携していません。
