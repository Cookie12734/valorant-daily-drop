# DAILY DROP

VALORANTの今日の個人ショップを表示するWindowsデスクトップアプリです。独自のWebサーバーやクラウドアカウントは不要で、このPCとインターネット接続だけで動作します。

## ダウンロードして使う

1. [自動更新に対応したプレビュー版](https://github.com/Cookie12734/valorant-daily-drop/releases/tag/v1.4.0-preview.4)から `DailyDrop-1.4.0-preview.4-win-x64.zip` をダウンロードします。
2. ZIPをすべて展開し、フォルダー内の **DailyDrop.exe** を起動します。EXEだけを移動せず、同梱ファイルと一緒に置いてください。
3. 初回は **Riotでログイン** を押し、アプリのRiot認証ウィンドウでログインします。二段階認証やCAPTCHAもその画面で完了します。「ログイン状態を保持する」を有効にしてください。
4. 認証後はショップを自動表示します。次回起動時も保存済みのセッションが有効なら、自動で今日のショップを取得します。

Windows x64向けです。Node.jsのインストール、ターミナル操作、ゲームの起動、Developer PortalのAPIキーは必要ありません。終了するときはショップ画面を閉じます。ログアウトは保存済みの認証Cookieも削除します。Riot側のセッションが失効した場合は再ログインが必要です。

配布版は独自のコード署名を付けていません。Windowsによって発行元の確認が表示される場合があります。

## アプリのアップデート

起動時と30分ごとにGitHub Releasesを確認し、現在より新しいバージョンがあれば「アップデート」を表示します。ボタンからリリース内容を確認し、「アップデートして再起動」を押すとWindows用ZIPとSHA-256を取得し、整合性確認・展開後にアプリを置き換えて再起動します。購入処理中は更新を開始できず、更新中の購入も停止します。ログイン情報と購入記録は引き継ぎます。

通常版は正式リリースのみ、プレビュー版はプレビューを含む新しいバージョンを対象とします。コミットの追加だけでは通知せず、新しいバージョンのリリース公開が必要です。配布時には `npm run package:win` が生成する `DailyDrop-<version>-win-x64.zip` と同名の `.zip.sha256` を添付してください。下書きは対象外です。

自動置き換えはWindows x64の配布版専用です。展開先の親フォルダーへの書き込み権限が必要です。旧版は親フォルダー内の `.daily-drop-update-*/previous` に退避し、置き換えや起動要求の失敗時には旧版へ戻します。起動後の動作不良まで自動検出するものではありません。正常起動を確認した後、不要になった退避フォルダーは手動で削除できます。更新機能のない旧版からの初回移行は、新しいZIPを手動で取得してください。

## コンパクト表示

デスクトップ版は420×460pxの小さなショップ画面で起動します。商品は2列で表示し、画像・名前・価格を確認できます。ウィンドウはドラッグで移動、端をドラッグでサイズ変更できます。既定では常に手前に表示し、画面内の右クリックメニューで解除できます。ログインが必要なときだけ従来のRiot認証ウィンドウを開きます。「ショップ／ナイトマーケット」で表示を切り替えられます。ナイトマーケットは割引後価格・通常価格・割引率を表示し、未開催時には案内を表示します。Web版にも同じ切り替えがあります。公開サイト単体ではRiot認証は行えません。

## 残高確認

ログイン後、ショップ画面の「残高確認」からヴァロラントポイント（VP）、レディアナイトポイント（RP）、キングダムクレジット（KC）を確認できます。「更新」で再取得できます。残高は保存せず、ログアウトすると表示を消去します。Riot Client経由のローカル補助サーバーでも利用できます。[通貨の正式名称（Riot Games）](https://support.riotgames.com/ja-jp/valorant/gameplay/valorant-console-guide)

## VPの購入（実験的）

残高確認の「VPを購入」、またはスキン購入時のVP不足の案内から、Riotの公式購入画面をアプリ内の別ウィンドウで開けます。**Riot Clientを起動し、DAILY DROPと同じアカウントでログインしてください。** ゲームの起動は不要です。金額・支払方法はRiotの画面で選択し、その画面で購入を確定します。

購入画面を閉じると、残高またはスキン購入の価格・残高を再取得します。スキン購入は自動確定しません。画面を閉じただけでは課金の成功と判断しません。VPの反映が遅れる場合は追加購入せず、時間をおいて残高を更新してください。

アカウントの登録国とRiot Clientの決済設定から接続先を選び、Riotの決済セッションAPIで公式画面を開きます。Riot Clientとのアカウント不一致、未対応地域、認証・通信エラー時は画面を開きません。セッションURL・トークンはショップ画面やディスクに保存せず、決済用の一時ブラウザーセッション内でのみ扱います。決済用ブラウザーにはNode.js・preloadを与えず、支払情報の読み取りや自動入力はしません。Riotと決済事業者のHTTPSページに接続します。支払方法によって別ウィンドウや外部サービスでの本人認証が必要です。

2026年10月9日、日本のアカウントで決済セッションの生成と、アプリ内での日本円のVP価格・支払方法表示を確認しました。実際の課金・3Dセキュア完了・VP反映は未検証です。公開の開発者向け決済APIではないため、Riot側の仕様変更により利用できなくなる可能性があります。

## 通常ショップ・アクセサリーストアの購入（実験的）

ナイトマーケットの右隣の「アクセサリーストア」で、ガンバディー・スプレー・プレイヤーカード・タイトルとKC価格、更新までの時間を確認できます。商品を選ぶと、通常ショップと同じ確認画面からKCで購入できます。購入前に最新のKC残高と購入後の残高を表示し、「○○ KCで購入を確定」を押すまで送信しません。アクセサリーの購入完了後はショップを再取得します。KC購入は[Riotの案内](https://support.riotgames.com/en-us/valorant/store/kingdom-credits-faq)により返金対象外です。実アカウントのKCを消費するテストは行っていません。

ログイン後、通常ショップのスキンを押して「購入内容を確認」を選びます。最新の価格、VP残高、購入後の残高を確認し、「○○ VPで購入を確定」を押したときだけ購入要求を送信します。バンドル、ナイトマーケット、プレビュー・読み込みファイルからの購入には対応していません。

送信前に商品・価格・残高・未所持であることを再確認します。確認内容は60秒で失効します。結果が不明な場合は自動再送せず、「購入結果を確認」から注文状態と所持状況を照合します。結果未確認の間は、アプリを再起動しても次の購入を止めます。記録の破損や保存失敗時も購入を止めます。

実アカウントのVPを消費するテストは行っていません。[非公式のCreate Order定義](https://github.com/PrometheuzzZ/valorant-api-docs/blob/trunk/valorant-api-types/src/endpoints/store/CreateOrder.ts)に基づく実験的な実装です。`XID`には要求ごとに生成したUUIDを使用しますが、その識別子の意味と現在の認証方式での購入成功は未確認です。APIには確認価格を拘束するフィールドが確認できていないため、送信直前の再確認を行ってもサーバー側の価格変更を原子的に防ぐことはできません。未確認の購入要求を別の形式で送り直す処理はありません。

## 接続先と保存する情報

- Riotの認証・アカウント・ショップAPIへ、このPCから直接接続します。
- 更新確認と配布ファイル取得のためGitHubへ接続します。Riotの認証情報は送信しません。
- [Valorant-API](https://valorant-api.com/)からスキンの名前・画像とクライアントバージョンを取得します。フォントはGoogle Fontsから読み込みます。これらへRiotトークンを送信しません。
- 独自サーバー、公開サイトへのログイン情報送信、利用状況の収集はありません。
- パスワードは分離されたRiotページへ直接入力し、アプリは読み取り・保存しません。Google・Appleなど外部サービス経由の認証は対象外です。
- 再起動後のログイン復元用Cookieは `%APPDATA%\DailyDrop` に保存します。Riotの有効期限は変更しません。ショップ取得用アクセストークンはメモリー内だけで扱います。
- アプリ内の画面にはスキンID・価格・取得／更新時刻・リージョンを返し、トークンを渡しません。
- 二重送信を防ぐ購入記録を `%APPDATA%\DailyDrop\purchase-state.json` に保存します。直近の購入の商品・価格・注文ID・状態と、アカウントを照合するハッシュを含み、認証トークンは含みません。ログアウト後も購入記録は保持します。購入結果が未確認のときは削除しないでください。

内部では、このPCからだけアクセスできる `127.0.0.1` の空きポートで同梱画面を配信します。利用者がサーバーを用意する必要はなく、アプリ終了時に停止します。認証・ログアウト・ショップ取得は同一オリジンのJSON POSTに限定しています。ネットワークへの公開や多人数共有は想定していません。

全ローカルAPIは、起動ごとに生成する256ビットの秘密トークンが必要です。デスクトップではメインプロセスがショップ画面のAPI通信だけに付与し、画面のJavaScript・URL・保存領域には渡しません。HostやOriginだけを偽装した別プロセスからの呼び出しは拒否します。ただし、同じOSユーザーの権限でプロセスメモリーを読み取れるプログラムや、アプリのファイルを改変できるプログラムまで隔離する仕組みではありません。

## 非公式方式の制約

Riotの[公式VALORANT API](https://developer.riotgames.com/docs/valorant)には個人ショップ取得用の公開エンドポイントがありません。[非公式認証の調査資料](https://valapidocs.techchrism.me/endpoint/auth-request)に基づくクライアントであり、承認済みRSO連携ではありません。Riot側の仕様変更や認証制限により利用できなくなる場合があります。

2026年10月4日、従来版で実アカウントのログインからv3 Storefront APIによるショップ表示まで利用者による確認が完了しています。デスクトップ版の実アカウントによる再起動後の自動表示は、別途実機確認が必要です。保存Cookieのプロセス間の引き継ぎ・削除はテスト用Cookieで検証済みです。

## ソースから起動・配布する

開発時のみNode.js 22.12以降が必要です。

```powershell
git clone https://github.com/Cookie12734/valorant-daily-drop.git
cd valorant-daily-drop
npm ci
npm start
npm test
node node_modules/electron/cli.js scripts/desktop-smoke.mjs
npm run package:win
```

Windows上で `npm run package:win` を実行すると、`releases/` に実行可能なフォルダー、ZIP、SHA-256ファイルを作ります。インストール済みElectronを同梱し、配布先でnpmを実行する必要はありません。認証情報・exports・開発用ファイルは同梱しません。

`dist/` は同梱画面、`scripts/desktop.mjs` はデスクトップウィンドウ、`scripts/riot-login.mjs` は認証・ショップ取得、`scripts/local-server.mjs` はアプリ内のローカル配信です。Electron以外はNode.js標準機能を使用します。

従来の起動中Riot Client経由の取得は `npm run start:client`、JSON書き出しは `npm run shop` で利用できます。静的ホスティング版はプレビュー・ダウンロード案内・ファイル表示のみ提供します。

`start:client` はターミナルに表示される専用URLをブラウザーで開いてください。URLにはその起動中だけ有効な秘密トークンを含むため、共有しないでください。読み込み後はURLから取り除き、再読み込み用にそのタブのsessionStorageで保持します。サーバー再起動後は、新しく表示されたURLを開き直してください。

VALORANTおよびスキン画像の権利はRiot Gamesに帰属します。本プロジェクトはRiot Gamesと提携していません。
